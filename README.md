# Open Repositories for iOS Hacking / Security Research Apps

A curated list of open-source repositories for iOS security research, penetration testing, and reverse engineering.

---

## Exploitation & Jailbreaking

| Repository | Description |
|---|---|
| [checkra1n / pongoOS](https://github.com/checkra1n/PongoOS) | Pre-boot execution environment used by the checkra1n jailbreak. |
| [unc0ver](https://github.com/pwn20wndstuff/Undecimus) | A full-featured jailbreak for iOS 11.0–13.5. |
| [Dopamine](https://github.com/opa334/Dopamine) | Semi-untethered jailbreak for iOS 15 and 16. |
| [palera1n](https://github.com/palera1n/palera1n) | Checkm8-based jailbreak for iOS 15 and 16. |
| [Fugu15](https://github.com/pinauten/Fugu15) | iOS 15 jailbreak proof-of-concept by Linus Henze. |

---

## Reverse Engineering & Analysis

| Repository | Description |
|---|---|
| [Frida](https://github.com/frida/frida) | Dynamic instrumentation toolkit for iOS, Android, and more. |
| [Ghidra](https://github.com/NationalSecurityAgency/ghidra) | NSA open-source reverse engineering framework with ARM64/iOS support. |
| [class-dump](https://github.com/nygard/class-dump) | Command-line tool to examine Objective-C runtime information in Mach-O files. |
| [dsdump](https://github.com/DerekSelander/dsdump) | An improved nm + Objective-C & Swift class-dump tool. |
| [iOSRE](https://github.com/kpwn/iOSRE) | Wiki and resources for iOS reverse engineering. |

---

## Network & Traffic Interception

| Repository | Description |
|---|---|
| [mitmproxy](https://github.com/mitmproxy/mitmproxy) | Interactive HTTPS proxy for intercepting and modifying traffic. |
| [Proxyman](https://github.com/ProxymanApp/Proxyman) | Native macOS app for intercepting iOS HTTP/HTTPS traffic. |
| [Burp Suite Community](https://portswigger.net/burp/communitydownload) | Widely used web security testing platform with iOS proxy support. |
| [SSL Kill Switch 2](https://github.com/nabla-c0d3/ssl-kill-switch2) | Tweak to disable SSL certificate validation on iOS. |

## Static Analysis

| Repository | Description |
|---|---|
| [MobSF](https://github.com/MobSF/Mobile-Security-Framework-MobSF) | Automated mobile (iOS/Android) security testing framework. |
| [objection](https://github.com/sensepost/objection) | Runtime mobile exploration toolkit powered by Frida. |
| [ipatool](https://github.com/majd/ipatool) | Command-line tool to download IPA files from the App Store. |
